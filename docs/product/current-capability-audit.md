## 仍需完成的闭环

1. 用户分批审核 PR #1、#3–#7 的依赖链；PR #2 为独立产品基线文档。集成后在 `main` 基线上继续；当前本机需安装 FFmpeg/ffprobe 供实际组装，仓库不捆绑二进制。
2. 选择试产首条配音路径：一项用户可用的 TTS 服务或经确认的人工录音导入；PR #7 只完成源绑定，不含 Provider。逐字台词、角色声音、时间线、字幕与局部返工都需验证。
3. 在目标播放设备检查成片画面、对白、混音和字幕，补上创作者审片证据；自动检查不替代叙事与审美判断。
4. 自动化门槛通过后，再用用户提供的小说素材私下连续制作三集，记录实际费用、人工耗时、等待、失败、返工和创作者验收；不将原文、衍生文本、成片或凭据提交公开仓库。
