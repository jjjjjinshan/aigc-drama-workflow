## 配音路线调研（2026-11-02）

| 路线 | 适用价值 | 当前限制 | 结论 |
|---|---|---|---|
| Windows SAPI（Microsoft Huihui） | PR #9 Adapter 已在本机经确认任务生成绑定 `VLINE-*` 的 PCM WAV，并接入时间线、SRT 与 FFmpeg 合成视频组装；不发送内容到云端 | 样音尚未由创作者审听；系统声线不代表角色表演质量，集成画面为合成素材 | 可作为零费用技术基线；是否适合试产对白待试听决定 |
| 腾讯云 TTS | 官方 API 支持 SSML；多情感音色支持情感类别/强度参数，且 API 可返回 WAV。更贴合普通话角色台词与逐句重做。2026-11-02 官方价目显示“超自然大模型 2.0”按量价为 2.5 元/万字符 | 需要确认账号区域、音色可用性、免费包及后付费开关；音色表现须先盲听比较，且发往服务商的台词会离开本机 | 建议作为有费用上限的中文剧情配音候选；仅用户授权后做短句样音与试产 |
| OpenAI TTS | 多语言输入，生成时可用指令控制语气、语速与情绪 | 官方说明音色当前针对英语优化；本项目是中文剧情台词，是否合适需中文实听。未据当前价目页确认本次模型的准确费用 | 暂不作为首个中文配音候选 |
| 人工录音导入 | 表演与角色区分由创作者直接控制；不依赖某个在线 TTS API | 录制、收音、命名、返录与台词/字幕绑定尚无导入链路，时间成本未测 | 后续可作为质量参照和混合制作路线 |

上述价目与能力来自[腾讯云在线 TTS 计费说明](https://cloud.tencent.com/document/product/1073/34112)、[腾讯云基础语音合成 API](https://cloud.tencent.com/document/product/1073/37995)和[OpenAI TTS 指南](https://developers.openai.com/api/docs/guides/text-to-speech)。费用随账户配置、音色和实际字符数变化；正式试产前需按已批准配音本字符数重新估价，逐条 job 保留费用预览与人工确认。

## 仍需完成的闭环

1. 用户分批审核 PR #1、#3–#7、#9；PR #3–#7 按依赖顺序，PR #9 随 PR #7 集成。PR #2 与 PR #8 独立于运行时代码链。集成后在 `main` 基线上继续；实际组装需本机安装 FFmpeg/ffprobe，仓库不捆绑二进制。
2. 先由创作者试听 SAPI Adapter 输出，决定它是否只作为零成本技术基线，或能承担试产配音。若声音质量不够，再在用户已有账户中评估中文剧情 TTS；任何在线样音须先核实预算、扣费状态并逐项确认。当前 SAPI 验证只覆盖一条短句和合成画面，不能视为配音质量或剧集验收。
3. 在目标播放设备检查成片画面、对白、混音和字幕，补上创作者审片证据；自动检查不替代叙事与审美判断。
4. 自动化门槛通过后，再用用户提供的小说素材私下连续制作三集，记录实际费用、人工耗时、等待、失败、返工和创作者验收；不将原文、衍生文本、成片或凭据提交公开仓库。
